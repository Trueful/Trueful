# Glossary (用語集)

* **Workspace**: Truefulにおける作業の最小単位。1つのプロジェクトやタスクに対応し、独立した設定、Cookie、履歴を持つ。
* **Inspector**: 画面右または下部に配置される、開発者向けの詳細情報・セキュリティモードを表示するパネル。
* **Agent**: DOMやネットワークリクエストを監視し、テストや操作の自動化を提案・実行するローカルAIの実体。
* **Broker**: ローカルAI（Ollama等）とクラウドAIのリクエストを統合管理し、キューイングやコンテキスト付与を行う中間レイヤー。
* **Dormant (休止状態)**: リソース節約のため、メモリ上から解放された状態のWorkspaceまたはタブ。再度フォーカスされるとリロードされる。
* **Manifest**: Workspaceの設定（URL、ピン留めされたタブ、プラグイン、セキュリティ設定など）を記述したJSONファイル。
* **Ambient Indicator**: 画面の隅などに常時表示され、現在のセキュリティモードやAIの待機状態などを静かに伝えるUI要素。
