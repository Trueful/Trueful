# Consent Fatigue対策（Inspector Agent補強）

Tier C（状態変更を伴う操作）の同意疲れ対策として、**個別フィールドの自動承認は導入しない**——これはTier Cの不変条件（毎回同意・設定でオーバーライド不可）に直接抵触するため。

## 解決策：バッチレビューUI

複数のTier C候補が同時に存在する場合、1つの画面にまとめて一覧表示し、それぞれに対して個別に承認/却下を選べるようにする。同意そのものを省略するのではなく、同意にかかるダイアログの往復回数を減らす方向で疲労を軽減する。
