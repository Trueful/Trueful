# Trueful Philosophy

「開発者の時間を奪わない。」

Truefulは単なるWebブラウザではなく、開発者の作業環境（Workspace）として再定義されたツールです。本ドキュメントでは、Truefulがなぜ存在するのか、そしてどのような思想で設計されているのかを定義します。

## Mission

**開発者が最短で、安全に、迷わずWebを閲覧できる体験を提供する。**

Webを閲覧する道具ではなく、開発者の作業環境（Workspace）として機能することが私たちの使命です。

## Vision

**Webを開発者仕様へ再構成する。**

ドキュメント、API、GitHub、SDK、Changelog、Statusを、最もアクセスしやすい場所へ配置し直します。これにより、開発者が情報探索において迷わない状態を実現します。

## Design Motto

**Fast to Work. Easy to Reason. Hard to Misuse.**

* **Fast to Work**: 目的達成までの時間を最小化する。
* **Easy to Reason**: 予測可能で透明性の高い振る舞いを保証する。
* **Hard to Misuse**: 混乱を排除し、失敗に対して寛容な設計とする。

## Priority Layers

### Layer 0 — Core Values（不変の価値観）

* **Developer First**: 開発者自身の体験を最優先とする。一般ユーザー向けの過剰な親切さは、開発者にとっては時にノイズとなるため排除する。
* **Purpose First**: 開発という目的に特化する。エンターテインメントや汎用的なWebブラウジングは他のブラウザに譲り、作業環境としての純度を高める。
* **Time First**: 開発者の時間を奪わない。無駄なアニメーションや探しにくい設定画面を排除し、最短距離で目的の操作を行えるように設計する。

### Layer 1 — Interaction Contract（UXの契約）

* **No Confusion**: モードやコンテキストの混同を防ぐ。今どのプロジェクトで、どのようなセキュリティレベルで作業しているかが一目でわかる状態を維持する。
* **Predictable**: 勝手に動かない。予測できないAIの自動実行や、裏側での暗黙的な状態変更を排除し、常にユーザーのコントロール下に置く。
* **Zero Noise**: 今必要な情報だけをデフォルトで表示する。設定や追加情報はProgressive Disclosureの原則に基づき、必要な時にだけ展開させる。

### Layer 2 — Technical Freedom（技術的自由度）

* **Everything Configurable**: 開発者は道具を自分の手に馴染ませる権利がある。すべての振る舞いは設定ファイルによってカスタマイズ可能でなければならない。
* **Local First**: 開発者はネットワーク状況に左右されるべきではない。ツールはインターネットがなくても動くべきであり、クラウドは利便性を提供する存在であって依存先ではない。
* **Keyboard First**: マウスへの持ち替えは思考の中断を生む。全ての操作はキーボードからシームレスにアクセス可能とする。

### Layer 3 — Work Unit Model（作業単位）

* **Workspace First**: タブは情報の単位として弱すぎる。情報の起点と単位を、プロジェクトやタスクに紐づくWorkspaceとして扱うことで、作業のコンテキストを維持する。
