# ADR 0001: 実行基盤は Electron + Chromium とする

## Status
Accepted

## Context
クロスプラットフォームのデスクトップアプリケーションを開発するにあたり、Tauri や Tauri v2、あるいはネイティブ言語での開発など複数の選択肢がある。しかし、ブラウザとしての高度な制御（CDPの利用、証明書処理のフック、独立したセッションパーティション）が要求される。

## Decision
実行基盤として Electron を採用し、全OSでレンダリングエンジンを Chromium に固定する。

## Consequences
* **Pros**: 全OSで動作の一貫性が保たれ、WebViewの差異によるバグを防げる。CDPを介した深いレベルでのインスペクトが可能。
* **Cons**: アプリケーションのバイナリサイズが大きくなり、メモリ消費も増加する。
