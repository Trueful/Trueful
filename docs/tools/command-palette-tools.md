# 開発者向け便利ツール集（Command Palette拡張）

全てTier A相当（生成・変換・表示のみ、副作用なし）を原則とする。例外は各項目末尾に注記。

## 変換・エンコード系

- JSON整形・検証（pretty print、バリデーションエラー箇所ハイライト）
- JWTデコーダー（ヘッダー/ペイロード分解、有効期限切れを色分け）
- Base64 / URLエンコード・デコード
- Hex / Binary / Decimal / Octal 相互変換
- Unixタイムスタンプ⇄日時変換（タイムゾーン指定可）
- Cron式デコーダー（`0 3 * * 1` → 自然文変換）
- HTMLエンティティ エンコード/デコード
- Markdown ⇄ HTML 変換プレビュー（テンプレート選択式）
  - 変換結果を素のHTMLではなく、簡易CSSを同梱したスタンドアロンHTMLとして出力
  - コードブロックはfenceの言語指定（```js`等）を読み取り、背景色・等幅フォント・行番号で「一目でコードと分かる」見た目にする
  - スタイルテンプレートを複数用意し、ユーザーがプルダウン/Command Paletteから選択：
    - GitHub風：README.md風の白背景、コードは薄灰背景
    - Notion風：余白多め、柔らかい配色
    - ダーク：コード閲覧向けの目に優しい配色
    - 印刷向け：装飾を抑え、記事化・PDF化前提のレイアウト
  - 出力はファイル保存 or クリップボードコピー。生成のみでネットワークアクセスなし＝Tier A
- YAML ⇄ JSON / CSV ⇄ JSON 変換
- URLパーサー（クエリパラメータを分解表示）
- MIME typeルックアップ（拡張子⇄MIMEタイプ）
- User-Agent文字列パーサー
- Slug生成器（タイトル→URL-safe slug、日本語対応）
- Unicodeコードポイント検索

## 検証・デバッグ系（Inspector Bar連携）

- cURLコマンド生成（Network欄から右クリック→「curlとしてコピー」）
- HTTPステータスコード早見表
- レスポンスヘッダー比較（2リクエストの差分表示、モード切替検証にも活用）
- 正規表現テスター（ライブマッチハイライト）
- Diffビューア（テキスト/JSON/API応答の差分）
- Content-Security-Policyパーサー（CSPヘッダーを人間可読に整形）
- SSL証明書の有効期限一覧（開いている全originの証明書状態を集計表示）

**注記**：DNSルックアップ結果ビューアは「既にブラウザが取得済みのキャッシュ情報を表示するだけ」ならTier A。新規に能動的なDNSクエリを発行する版はTier B相当（読み取り専用の外部通信）に分類し直す必要がある。

## 暗号・ハッシュ系

- ハッシュ計算機（MD5/SHA1/SHA256/SHA512、テキスト/ファイル入力）
- HMAC計算機
- Ed25519/RSA 鍵ペア生成・可視化
- X.509証明書ビューア（Inspector Barで見つけた証明書をドリルダウン）
- パスワード/パスフレーズ生成器（エントロピー表示付き）
- bcrypt/argonハッシュ生成・検証

## 数学・物理系

- 単位変換（SI単位）、ベクトル演算電卓
- 座標変換（極座標⇄直交座標、度⇄ラジアン）
- 統計計算機（平均・分散・標準偏差）
- 小規模行列演算電卓（積・逆行列）

## 生成系

- UUID / ULID生成器
- QRコード生成（ローカル開発URLをスマホ実機で即確認）
- Favicon / OGPプレビュー（共有時の見え方を事前確認）
- スニペット管理（Command Paletteから即座に呼び出し）

## 環境・ローカル開発系

- .envファイル簡易ビューア（値はマスク表示可能）
- ローカルポート検出（localhost:3000等、起動中プロセスを一覧表示）
- カラーピッカー + WCAGコントラスト比チェッカー（Inspector Agentのa11y監査と機能共有）

## 日本語・文章処理系

- 文字数カウンター（原稿用紙換算、全角/半角区別）
- ふりがな生成（漢字へのルビ付与）
- 全角⇄半角変換
- 日本語禁則処理チェッカー

## デザイン・アクセシビリティ系

- カラーパレット生成（ベースカラーからの配色提案）
- ローカルインストール済みフォントのプレビュー一覧
- レスポンシブブレークポイントシミュレーター（実リサイズなしでビューポート疑似切替）

## 個人生産性系

- ポモドーロタイマー（Inspector Barに残り時間表示）
- クリップボード履歴（Command Paletteから検索して再利用）
- Workspace紐付けのクイックメモ/Todoキャプチャ

## 実装上の位置付け

- Security Profileに関わらず常時利用可能（副作用なし＝Tier分類の対象外）
- Plugin API（Worker Thread）経由でも安全に追加できる：ネットワーク不要、入出力がJSON往復のみのため、[ADR-003](../architecture/adr/adr-003-worker-thread.md) の権限モデルと親和性が高い
- Zero Noise原則：Command Palette検索でのみ表示され、デフォルトUIを圧迫しない

## 追加機能（Command Palette・ツール・連携）

- **Fuzzy Search**：Command Paletteの検索はFuse.js等によるあいまい一致を採用する。前方一致のみではTime Firstを満たせない
- **Developer Homeのカスタマイズ**：静的リンク集ではなく、ローカルMarkdownファイルとして編集可能にする。既存のMarkdown→HTML変換ツール（テンプレート選択式）をそのまま転用する
- **ツール実行履歴**：Command Palette経由の変換ツール（Base64等）の入出力履歴をローカルのみで直近N件保持する
- **スニペット管理**：SQLiteではなくファイルベース（JSON/Markdown）で保存し、Git管理可能にする（Reproducibility #10との整合）
- **Gitブランチ連動Workspace切替**：ブランチ変更を検知した場合も自動切替は行わない。「関連Workspaceに切り替えますか？」という提示のみに留める（Predictable #8、[緊張2](../philosophy/resolved-tensions.md) の解決パターンの再適用）
- **DevTools統合**：標準のChromium DevTools（F12）はそのまま維持し、独自実装しない。Inspector Agentは別パネルとして共存させ、DevToolsのNetwork欄に「Inspector Agentへ送る」的な連携ボタンを設ける程度に留める
- **オフラインUX**：ネットワーク切断時は専用のオフラインページを表示し、ローカルAI・ローカルツール・キャッシュ済みページなど「オフラインでも使える機能一覧」を提示する
- **CORS無効化トグル**：SecurityProfileのCustomプロファイル内の一設定として追加する（Productionには存在しない）
