# クラッシュレポート方針（確定）

Sentry（クラウド版）を採用。収集方針はオプトイン・デフォルトOFF、送信内容は事前明示（Transparency #9）。Local First（#11）の型に従い、送信するかどうかは常にWorkspace/アプリ設定でユーザーが選択できる状態を維持する。

## 規模の見込み

想定ユーザー規模（初年度数百人、[普及戦略](../roadmap/go-to-market.md) 参照）ではDeveloper無料枠（月5,000エラー、30日保持）で当面収まる見込み。運用の手間がゼロである点を優先し、自前ホスト（GlitchTip等）は採用しない。将来エラー量が増え無料枠を超える場合はTeam tier（$26/月）へ移行する。
