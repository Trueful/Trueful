# Mission / Vision

## Mission

Provide developers with an experience where they can browse the web by the shortest path, safely, and without confusion.

A browser is not a tool for browsing the web — it is the developer's **Workspace**.

## Vision

Reconstruct the web for developers.

Relocate documentation / APIs / GitHub / SDKs / changelogs / status pages to the most accessible places.

Developers never get lost.
