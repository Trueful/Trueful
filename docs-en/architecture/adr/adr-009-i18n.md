# ADR-009: Internationalization (i18n)

**Status**: Decided

## Decision

Initial scope is Japanese/English only. Use a standard i18n library (e.g. i18next) with resource files (`locales/ja.json` / `locales/en.json`); no custom string-management system.

## Notes

- OS locale is auto-detected on first launch; manual switching is also available from the settings screen (Everything Configurable)
- Languages beyond ja/en are a Non-goal for now

## Fonts

- UI font: Meiryo (covers both Japanese and English glyphs adequately, no fallback management needed for English)
- Code display: JetBrains Mono
