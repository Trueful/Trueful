# Mission / Vision

## Mission（使命）

開発者が最短で、安全に、迷わずWebを閲覧できる体験を提供する。

ブラウザはWebを閲覧する道具ではなく、**開発者の作業環境（Workspace）** である。

## Vision（目指す姿）

Webを開発者仕様へ再構成する。

ドキュメント / API / GitHub / SDK / Changelog / Status を最もアクセスしやすい場所へ配置し直す。

開発者は迷わない。
