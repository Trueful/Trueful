# ログ仕様

| 項目 | 内容 |
|---|---|
| 残すもの | エラーログ（エラーコード付き）、Tier実行ログ、SecurityProfile切替履歴、tierRationale |
| 残さないもの | フォーム入力内容、Cookie値そのもの（送信有無のみ記録）、パスワード・認証情報 |
| ローテーション | 7日分保持、ファイルサイズ上限50MBで古いものから削除 |
| 匿名化 | ローカルログは匿名化不要（Local First）。エクスポート/共有時およびSentry送信時はPIIスクラビングを必須とする |

## 利用統計の方針（確定）

クラッシュレポート（Sentry、opt-in）とは別に、機能利用頻度などの匿名利用統計はv1では一切収集しない。Local First＋信頼構築優先の帰結——ニッチな信頼が生命線のツールで、プロダクト分析目的の統計収集はコストに見合わない。
