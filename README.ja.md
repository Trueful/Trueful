# Trueful

> 開発者のために設計されたブラウザ。

**Fast to Work. Easy to Reason. Hard to Misuse.**

---

## Mission（使命）

Truefulは、開発者が必要な情報へ最短で、安全に、迷わず到達できる体験を提供します。

ブラウザはWebページを表示する道具ではありません。

開発者の作業環境（Workspace）であるべきだと考えています。

---

## Vision（目指す姿）

TruefulはWebを開発者仕様へ再構成します。

ドキュメント、API、GitHub、SDK、Changelog、Statusページなど、
開発に必要な情報へ最短距離でアクセスできるブラウザを目指します。

---

## 基本理念

- Developer First
- Time First
- No Confusion
- Transparency
- Workspace First
- Local First
- Keyboard First
- Everything Configurable
- Failure Friendly
